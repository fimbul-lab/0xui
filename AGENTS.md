## ui-sdk

Before using ui-sdk (`@ui-sdk/react`, `@ui-sdk/core`):

- Follow the `ui-sdk` skill if it is installed.
- Read `node_modules/@ui-sdk/react/docs/llms.txt`.

To build a new component, also:

- Search `node_modules/@ui-sdk/react/docs/core.md` by heading.
- Read `node_modules/@ui-sdk/react/docs/rendering.md`.
