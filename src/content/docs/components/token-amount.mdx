import { Card } from "@astrojs/starlight/components";

Formats a raw `bigint` amount for display. Precision is never lost to floating point, and amounts always round toward zero, so a balance never looks larger than it is. Hover to see the exact amount.

<Card>
  <Default client:load />
</Card>

## Installation

```bash
npx shadcn@latest add @0xui/token-amount
```

## Usage

```tsx
import { TokenAmount } from "@/components/token-amount";

<TokenAmount value={balance} decimals={6} symbol="USDC" />;
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `bigint` | — | Amount in the token's smallest unit. |
| `decimals` | `number` | — | Token decimals. |
| `symbol` | `string` | — | Shown after the amount. |
| `maxDecimals` | `number` | `4` | Maximum fraction digits. |
| `compact` | `boolean` | `false` | Compact notation, e.g. `1.2M`. |
| `price` | `number` | — | Price of one token. Adds a fiat line. |
| `currency` | `string` | `"USD"` | ISO 4217 currency for the fiat value. |
| `locale` | `string` | runtime locale | Number formatting locale. |
| `animate` | `boolean` | `false` | Morph the amount and fiat value when they change, with [Morph Text](/components/morph-text/). Leave off in long lists. |
