Tries three sources in order: your `src` URL, the built-in icon for the symbol, then the symbol's first two letters.

<Card>
  <Default client:load />
</Card>

## Installation

```bash
npx shadcn@latest add @0xui/token-icon
```

## Usage

```tsx
import { TokenIcon } from "@/components/token-icon";

<TokenIcon symbol="USDC" />;

// With a token list
<TokenIcon symbol={token.symbol} src={token.logoURI} />;
```

## Examples

### With chain badge

The same token on different chains is easy to mix up. `chainId` adds the chain's logo in the corner.

<Card>
  <WithChain client:load />
</Card>

```tsx
<TokenIcon symbol="USDC" chainId={8453} size={40} />
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `symbol` | `string` | — | Token symbol. Used for the built-in icon, the fallback and the accessible label. |
| `src` | `string` | — | Logo URL. Takes priority over the built-in icon. |
| `chainId` | `number` | — | Show this chain's logo as a corner badge. |
| `size` | `number` | `24` | Diameter in px. |
| `variant` | `"background" \| "branded" \| "mono"` | `"branded"` | Style of the built-in icons. |
