## IPFS

`ipfs://` links go through `https://ipfs.io/ipfs/` by default. The public gateway is slow and rate-limited, so use your own in production:

```tsx
<NftCard gateway="https://my-gateway.mypinata.cloud/ipfs/" … />
```

## States

| `data-phase` | What the user sees |
| --- | --- |
| `loading` | A skeleton measured from the card's own layout. |
| `ready` | Image, name, collection and id. |
| `not-found` | "Token not found": no `tokenURI`/`uri`, so it's not an NFT or doesn't exist. |
| `metadata-error` | "Metadata unavailable": the token exists, but its metadata host failed. Usually a rate-limited public IPFS gateway. |

Helpers: `useNft`, `fetchNftMetadata`, `resolveUri` and `expandTokenUri` (ERC-1155 `{id}` substitution).
