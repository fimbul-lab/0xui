How much a trade can take from the pool before the price moves a given amount. Bids on the left are the quote token the pool gives up as the price falls. Asks on the right are the base token it gives up as the price rises. Both sides are valued in the quote token, so they share one axis.

The figures on top are ±2% depth, the measure Uniswap Labs and Kaiko use to compare liquidity across venues. Hover or use the arrow keys to read depth at any price.

## Usage

```tsx
import { DepthChart } from "@/components/depth-chart";
import { getLiquidityBins, poolPrice } from "@/lib/concentrated-liquidity";

const bins = getLiquidityBins(pool, ticks, { bins: 300 });

<DepthChart bins={bins} currentPrice={poolPrice(pool)} token0={eth} token1={usdc} />;
```

Pass enough bins to cover the widest window. With a tick spacing of 10, 300 bins reach about ±35%. Past the last bin the curve goes flat.

To show the numbers without a chart, call `getMarketDepth(bins, price, 2)`, or `readDepth` for a signed move in the displayed direction. `readDepth` and `sampleDepth` live in `@/lib/depth-chart-core` and need no framework.

## Loading

Leave out `bins` and `currentPrice` while it loads. The component shows a [skullet](https://skullet.lochie.me) skeleton in its own shape, "Loading market depth" for screen readers, and fades into the content when it arrives. The demo above loads for a second first.

## How depth is measured

Above the price the pool holds only token0, below it only token1. Walking out from the price, the chart adds up the tokens in each slice of the curve, and splits the slice the cut falls in along the constant-liquidity curve. Asks are valued at the current price, not the price after the move, so the two sides compare like for like.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `bins` | `LiquidityBin[]` | — | From `getLiquidityBins`. Leave out while loading. |
| `currentPrice` | `number` | — | Token1 per token0. Leave out while loading. |
| `token0` / `token1` | `{ symbol: string }` | — | Any `Token` fits. |
| `invert` | `boolean` | `false` | Quote in token0. |
| `window` | `number` | `10` | Visible move each side, in %. Setting it hides the window control. |
| `windows` | `number[]` | `[2, 5, 10, 25]` | Window options, as a segmented control. `[]` hides it. |
| `level` | `number` | `2` | Depth level for the headline figures and markers. |
| `height` | `number` | `180` | Plot height in px. |
| `locale` | `string` | runtime locale | Number formatting locale. |
