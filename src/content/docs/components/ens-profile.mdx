## Usage

```tsx
import { EnsProfile } from "@/components/ens-profile";

<EnsProfile name="vitalik.eth" />;

// Or by address: uses its primary name
<EnsProfile address={address} />;
```

<Preview>
  <ByAddress client:load />
</Preview>

ENS lives on Ethereum mainnet, so mainnet must be in your wagmi config. Pass `records` to read other text records. Unknown keys are fetched and returned by `useEnsProfile`, but not rendered.

## States

| `data-phase` | Meaning |
| --- | --- |
| `loading` | A skeleton measured from the avatar, name and address. |
| `ready` | Profile shown. |
| `not-found` | The name has no address, or the address has no primary name. |
