Copies a value to the clipboard. The icon turns into a checkmark for two seconds, and "Copied" is announced to screen readers.

## Installation

<Install name="copy-button" />

## Usage

```tsx
import { CopyButton } from "@/components/copy-button";

<CopyButton value={address} label="Copy address" />;
```

Always pass a specific `label`. It is the button's only accessible name.

## Examples

### Other button styles

Accepts every `Button` prop (the ui-sdk Button with 0xui's variants), including `variant` and `size`.

<Preview>
  <Outline client:load />
</Preview>

```tsx
<CopyButton value={hash} label="Copy transaction hash" variant="outline" size="icon" />
```

## States

| State             | What the user sees                                                                  |
| ----------------- | ----------------------------------------------------------------------------------- |
| Idle              | Copy icon.                                                                          |
| Copied            | Checkmark for `timeout` ms, "Copied" announced. `data-copied` is set on the button. |
| Clipboard blocked | Nothing changes and `onCopy` is not called.                                         |

## Props

Also accepts all `Button` props except `onClick` and `children`.

| Prop         | Type                      | Default      | Description                                                                                                                                                                                                             |
| ------------ | ------------------------- | ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `value`      | `string`                  | —            | Text to copy.                                                                                                                                                                                                           |
| `label`      | `string`                  | from `value` | Accessible label and tooltip. Name what it copies, so it's unique on the page for screen readers and browser agents. Defaults to `"Copy address"` for an address, `"Copy hash"` for a 32-byte hash, otherwise `"Copy"`. |
| `timeout`    | `number`                  | `2000`       | How long the copied state lasts, in ms.                                                                                                                                                                                 |
| `onCopy`     | `(value: string) => void` | —            | Called after a successful copy.                                                                                                                                                                                         |
| `copyIcon`   | `ComponentType \| false`  | `CopyIcon`   | Custom icon, or `false` to hide it.                                                                                                                                                                                     |
| `copiedIcon` | `ComponentType \| false`  | `CheckIcon`  | Custom icon, or `false` to hide it.                                                                                                                                                                                     |
