## Usage

```tsx
import { PositionCard } from "@/components/position-card";
import { v3Collect } from "@/lib/v3-position-manager";

<PositionCard
  position={{ tokenId, token0: usdc, token1: eth, fee: 500, tickLower, tickUpper, liquidity, fees0, fees1 }}
  pool={pool}
  prices={prices}
  invert
  getCollectTransaction={v3Collect({ positionManager, weth })}
  actions={<Button onClick={openRemove}>Remove</Button>}
/>;
```

## Reading a position

For Uniswap v3, read `positions(tokenId)` from the position manager. It returns the tokens, fee, ticks and liquidity. Its `tokensOwed0` and `tokensOwed1` only count fees up to the last time the position was touched, so get the real uncollected fees by simulating `collect` with the maximum amounts:

```ts
import { maxUint128 } from "viem";
import { positionManagerAbi } from "@/lib/v3-position-manager";

const { result: [fees0, fees1] } = await client.simulateContract({
  address: positionManager,
  abi: positionManagerAbi,
  functionName: "collect",
  args: [{ tokenId, recipient: owner, amount0Max: maxUint128, amount1Max: maxUint128 }],
  account: owner,
});
```

The amounts the position holds come from `getPositionAmounts(position, pool)` in `concentrated-liquidity`, exact to the wei.

## States

Out of range (it holds one token and earns nothing until the price comes back) and closed (all liquidity withdrawn). The status is on `data-status`.

The Collect fees button names its blocker ("No fees to collect"). `v3Collect` pays fees to the connected account and unwraps WETH to ETH when one side is native.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `position` | `Position<Token>` | — | `{ tokenId, token0, token1, fee?, tickLower, tickUpper, liquidity, fees0?, fees1? }`. |
| `pool` | `{ tick, sqrtPriceX96?, tickSpacing, decimals0, decimals1 }` | — | The position's pool. |
| `prices` | `TokenPrices` | — | Fiat totals. |
| `currency` | `string` | `"USD"` | ISO 4217 currency. |
| `invert` | `boolean` | `false` | Quote the range in token0. |
| `getCollectTransaction` | `(request) => tx` | — | Adds Collect fees. `v3Collect({ positionManager, weth })`. |
| `onCollected` / `onSubmitted` | `(receipt)` / `(hash)` | — | Collect callbacks. |
| `actions` | `ReactNode` | — | Extra footer buttons. |
| `locale` | `string` | runtime locale | Number formatting locale. |
