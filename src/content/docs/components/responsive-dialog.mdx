A centered dialog is out of thumb reach on a phone. This shell shows the same title and content as a centered dialog on larger screens and as a bottom sheet on small touch screens. The sheet can be swiped down to close.

It is what [Connect Wallet](/components/connect-wallet/) and [Token Select](/components/token-select/) open. Use it for your own pickers and small forms.

Open it on a phone, or in your browser's device mode, to get the sheet.

## Installation

<Install name="responsive-dialog" />

It installs the 0xui `Dialog` primitive, built on the ui-sdk Dialog and its sheet presentation.

## Usage

```tsx
import { ResponsiveDialog } from "@/components/responsive-dialog";

const [open, setOpen] = useState(false);

<ResponsiveDialog
  open={open}
  onOpenChange={setOpen}
  title="Slippage"
  description="Choose how much the price may move before the swap is cancelled."
  className="sm:data-[presentation=dialog]:max-w-sm"
>
  {content}
</ResponsiveDialog>;
```

`description` is read by screen readers and not shown. Write it for someone who can't see the content.

## Examples

### Force one

`mode="drawer"` or `mode="dialog"` skips the screen check.

<Preview>
  <ForcedDrawer client:load />
</Preview>

```tsx
<ResponsiveDialog mode="drawer" …>
```

### Your own breakpoint

By default `auto` asks ui-sdk, which picks the sheet on small touch screens. Pass `drawerQuery` to pick it with a media query instead, touch or not.

```tsx
<ResponsiveDialog drawerQuery="(max-width: 767px)" …>
```

### Headless

`useMediaQuery(query)` is the hook behind `drawerQuery`. It is false on the server and where `matchMedia` is missing, such as jsdom.

## Behavior

| Case                                         | What happens                                                                                                                                        |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Server render                                | Dialog. `auto` is decided each time it opens, in the browser.                                                                                       |
| The screen crosses the breakpoint while open | It keeps its presentation until it closes, and the content keeps its state.                                                                         |
| Long content in the sheet                    | The panel scrolls. The sheet stops at 85% of the screen height.                                                                                     |
| `className`                                  | Applies to the panel in both presentations. Target one with `data-[presentation=dialog]:` or `data-[presentation=sheet]:`. The sheet is full width. |

## Props

| Prop                    | Type                             | Default   | Description                                                                                                                                        |
| ----------------------- | -------------------------------- | --------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `open` / `onOpenChange` | —                                | —         | Control it.                                                                                                                                        |
| `title`                 | `ReactNode`                      | —         | Shown at the top.                                                                                                                                  |
| `description`           | `ReactNode`                      | —         | For screen readers. Not shown.                                                                                                                     |
| `mode`                  | `"auto" \| "dialog" \| "drawer"` | `"auto"`  | Pick by screen, or force one. `drawer` is the bottom sheet.                                                                                        |
| `drawerQuery`           | `string`                         | —         | Media query that picks the sheet in `auto` mode, in place of the small touch screen check.                                                         |
| `closeLabel`            | `string`                         | `"Close"` | Accessible name of the close button. Name it after the dialog, e.g. `"Close send form"`, so it stays unique for screen readers and browser agents. |
| `className`             | `string`                         | —         | Class for the panel.                                                                                                                               |
| `children`              | `ReactNode`                      | —         | Dialog content.                                                                                                                                    |
