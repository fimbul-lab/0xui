Holdings for a token list: total value on top, then one row per token with amount and value, largest first. All balances are read in one batch.

<Card>
  <Default client:load />
</Card>

Tokens use the [token list standard](/getting-started/token-lists/). The demo uses Uniswap's default list, loaded live with `useTokenList`.

## Installation

```bash
npx shadcn@latest add @0xui/portfolio
```

## Usage

```tsx
import { Portfolio } from "@/components/portfolio";

<Portfolio tokens={tokenList.tokens} prices={prices} />;
```

It shows the connected account's holdings, or pass `address` for anyone's. Only tokens on `chainId` (the current chain by default) are read. Tokens without a price are listed with "—" and left out of the total.

Headless: `usePortfolio({ tokens, prices })` returns sorted `rows`, `total` and `unpriced`.

<Aside type="tip" title="In production">
Over RPC, a portfolio costs one balance read per token, per user, per chain. We recommend an [index of the chain](/getting-started/indexed-data/), either your own (Postgres + ClickHouse) or a service like Goldsky. Pass its balances in:

```tsx
<Portfolio tokens={tokens} address={address} balances={balancesFromYourIndex} prices={prices} />
```
</Aside>


## States

| `data-phase` | What the user sees |
| --- | --- |
| `idle` | "Connect a wallet to see its tokens." |
| `loading` | Three skeleton rows. |
| `ready` | Total and rows. |
| `empty` | "No tokens from this list in this wallet." |
| `error` | Couldn't load balances. |

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `tokens` | `Token[]` | — | Tokens to check. |
| `prices` | `Record<symbol, number>` | — | Prices for values and the total. |
| `address` | `Address` | connected | Whose holdings. |
| `chainId` | `number` | current | Chain to read. |
| `hideZero` | `boolean` | `true` | Hide empty balances. |
| `currency` | `string` | `"USD"` | Currency for values. |
| `balances` | `Record<address, bigint>` | — | Balances from your own source. Skips RPC reads. |
| `pageSize` | `number` | `10` | Rows per page, with "Show more". |
