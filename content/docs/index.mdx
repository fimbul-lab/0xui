# Web3 Component Registry

A beautifully-designed, accessible component library for web3 applications. Built with modern tools and following the shadcn/ui registry pattern, making it easy to copy, customize, and integrate web3 components into your projects.

## What is this?

This is a registry of **production-ready web3 components** that you can copy and paste into your apps. Similar to [shadcn/ui](https://ui.shadcn.com), but specifically designed for web3 use cases.

Each component is:

- **Beautifully designed** with attention to detail and modern aesthetics
- **Fully accessible** following WCAG guidelines
- **Customizable** - copy the code and modify to your needs
- **Type-safe** with full TypeScript support
- **Framework agnostic** - works with React and modern frameworks

## Why a Registry?

Unlike traditional component libraries, this registry gives you:

- **Ownership** - Components live in your codebase, not in `node_modules`
- **Customization** - Modify components to fit your exact needs
- **No dependencies** - Only install what you need
- **Learning** - See exactly how components work under the hood

## Getting Started

### Installation

Install the required dependencies:

```bash
npm install viem wagmi @tanstack/react-query
npm install @radix-ui/react-dialog @radix-ui/react-dropdown-menu
npm install motion
npm install tailwindcss
```

### Add a Component

1. Browse the [components](/docs/components) section
2. Copy the component code
3. Paste it into your project
4. Customize as needed

### Configure Your Provider

Set up wagmi and viem in your app:

```tsx
import { WagmiProvider, createConfig, http } from "wagmi";
import { mainnet, sepolia } from "wagmi/chains";
import { QueryClient, QueryClientProvider } from "@tanstack/react-query";

const config = createConfig({
  chains: [mainnet, sepolia],
  transports: {
    [mainnet.id]: http(),
    [sepolia.id]: http(),
  },
});

const queryClient = new QueryClient();

function App() {
  return (
    <WagmiProvider config={config}>
      <QueryClientProvider client={queryClient}>
        {/* Your app */}
      </QueryClientProvider>
    </WagmiProvider>
  );
}
```

## Component Categories

Our components are organized by use case:

- **Wallet Connection** - Connect buttons, wallet selectors, and connection flows
- **Transaction UI** - Transaction modals, status indicators, and confirmations
- **NFT Display** - Image galleries, metadata displays, and collection views
- **Token Management** - Balance displays, transfer forms, and token lists
- **Network Switchers** - Chain selectors and network indicators
- **Forms & Inputs** - Web3-specific form components and validators

## Design Principles

Every component follows these principles:

1. **Accessibility First** - Built with ARIA attributes and keyboard navigation
2. **Mobile Responsive** - Works beautifully on all screen sizes
3. **Dark Mode Ready** - Includes dark mode variants out of the box
4. **Performance** - Optimized for fast load times and smooth interactions
5. **Type Safety** - Full TypeScript support with comprehensive types
