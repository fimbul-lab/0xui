## Installation

Copy the component into your project:

```bash
registry/components/chain-selector/chain-selector.tsx
```

## Dependencies

```bash
npm install wagmi viem @web3icons/react
npm install @radix-ui/react-popover @radix-ui/react-dialog @radix-ui/react-tabs lucide-react
```

## Usage

```tsx
import { ChainSelector, ChainSelectorDialog } from "@/registry/components/chain-selector/chain-selector";

// Basic usage (Popover version)
<ChainSelector />

// Dialog version (opens as a modal)
<ChainSelectorDialog />

// Icon-only mode (label accessible via tooltip and screen readers)
<ChainSelector iconOnly />
<ChainSelectorDialog iconOnly />

// Custom icons
<ChainSelector chainIcon={MyChainIcon} chevronIcon={ChevronDown} />

// Disable icons
<ChainSelector chainIcon={false} />
<ChainSelector disableIcons />

// Group chains by network type (mainnet/testnet) with tabs
<ChainSelector groupByNetwork />
<ChainSelectorDialog groupByNetwork />
```

## Examples

### Custom Icon Using Chain Name

Some icon APIs use chain names instead of chain IDs. You can use wagmi hooks to access chain data:

```tsx
import { ChainSelector } from "@/registry/components/chain-selector/chain-selector";
import { useChains } from "wagmi";
import { cn } from "@/lib/utils";

function ChainNameIcon({ chainId, className }: ChainIconProps) {
  const chains = useChains();
  const chain = chains.find((c) => c.id === chainId);

  if (!chain) return null;

  // Example: Use chain name for icon API
  return (
    <img
      src={`https://api.example.com/icons/${chain.name.toLowerCase()}.svg`}
      alt={chain.name}
      className={cn("size-6 rounded-full", className)}
    />
  );
}

export function App() {
  return <ChainSelector chainIcon={ChainNameIcon} />;
}
```

### Chain Name Badge Instead of Icon

Display chain name abbreviation as a badge:

```tsx
function ChainNameBadge({ chainId, className }: ChainIconProps) {
  const chains = useChains();
  const chain = chains.find((c) => c.id === chainId);

  if (!chain) return null;

  const abbreviation = chain.name
    .split(" ")
    .map((word) => word[0])
    .join("")
    .slice(0, 3)
    .toUpperCase();

  return (
    <div
      className={cn(
        "size-6 rounded-full border flex items-center justify-center text-xs font-medium bg-muted",
        className
      )}
    >
      {abbreviation}
    </div>
  );
}
```

### Using Llamao.fi Icons

```tsx
export function App() {
  return <ChainSelector chainIcon={LlamaoChainIcon} />;
}
```

The `LlamaoChainIcon` component uses wagmi's `useChains()` hook to look up chain data by ID and formats the chain name for the Llamao.fi API URL pattern.

### Dialog vs Popover

The component comes in two variants:

- **`ChainSelector`** - Uses a Popover (dropdown) that appears near the trigger button. Best for compact UIs and when you want the selector to appear inline.
- **`ChainSelectorDialog`** - Uses a Dialog (modal) that appears centered on the screen. Best for mobile experiences and when you want a more prominent selection experience.

Both components share the same props and functionality - choose based on your UI needs.

## Setup

Ensure your wagmi config includes the chains you want to display:

```tsx
import { createConfig, http } from "wagmi";
import { mainnet, sepolia, base } from "wagmi/chains";

const config = createConfig({
  chains: [mainnet, sepolia, base],
  transports: {
    [mainnet.id]: http(),
    [sepolia.id]: http(),
    [base.id]: http(),
  },
});
```

The component automatically reads from your wagmi configuration and displays all configured chains.

## Props

| Prop             | Type                                             | Default     | Description                                               |
| ---------------- | ------------------------------------------------ | ----------- | --------------------------------------------------------- |
| `chainIcon`      | `ComponentType<ChainIconProps> \| false`         | `undefined` | Custom chain icon. Pass `false` to disable.               |
| `chevronIcon`    | `ComponentType<{ className?: string }> \| false` | `undefined` | Custom chevron icon. Pass `false` to disable.             |
| `loaderIcon`     | `ComponentType<{ className?: string }> \| false` | `undefined` | Custom loader icon. Pass `false` to disable.              |
| `disableIcons`   | `boolean`                                        | `false`     | Disable all icons.                                        |
| `iconOnly`       | `boolean`                                        | `false`     | Hide label (accessible via tooltip and screen readers).   |
| `groupByNetwork` | `boolean`                                        | `false`     | Group chains by network type (mainnet/testnet) with tabs. |

`chainIcon` receives: `{ chainId: number; className?: string; variant?: "branded" | "mono" | "background" }`
